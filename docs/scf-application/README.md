# SCF Application — Draft Materials

Draft submission materials for the Stellar Community Fund, generated from the
real, current state of this repository. Every technical claim is sourced from
the codebase, the docs set, and the verification work recorded against it —
nothing is aspirational.

**Current process (verified against the live handbook, September 2026):** all
new projects enter via the Interest Form on
[communityfund.stellar.org](https://communityfund.stellar.org). Eligible
teams are invited by email to submit a full proposal to one of three SCF
Build Award tracks (Open, Integration, RFP) for a specific round. Up to
$150,000 in XLM, tranche-funded. Next round deadline at drafting time:
**SCF #46 — November 8, 2026** (confirm on the awards page before relying on
it — rounds close every ~6 weeks).

## Founder-input checklist (consolidated)

Complete these before submission — they are the **only** gaps in the drafts:

1. **Track choice** — confirm the Open Track Build Award recommendation with
   the SCF team via the Interest Form. *(project-overview.md)*
2. **Referral code** — include one if you have it; referrals weigh heavily.
   *(project-overview.md, team-and-links.md)*
3. **Public repo URL** — confirm `github.com/payflex-work/payflex` is public
   for reviewers. *(technical-summary.md, team-and-links.md)*
4. **GitBook URL** for the Stellar docs set, if published separately.
   *(technical-summary.md)*
5. **Award amount requested** + allocation split across the four use-of-funds
   categories. *(roadmap-and-ask.md)*
6. **Phase dates/durations** for the four-phase timeline. *(roadmap-and-ask.md)*
7. **Team members** — roles, backgrounds, relevant experience. *(team-and-links.md)*
8. **KYC names** — every individual contributor who must complete SDF's KYC
   form if awarded. *(team-and-links.md)*
9. **"Why this team can ship this"** — 2–4 sentences tying background to the
   remaining work. *(team-and-links.md)*
10. **Prior traction** — users, waitlist, partnerships, prior funding.
    *(team-and-links.md)*
11. **Links** — demo video / hosted testnet demo (strongly recommended for
    Open Track community vote), website, contact email, Discord handle,
    social profiles. *(team-and-links.md — a real demo video now exists:
    `demo/payflex_offline_demo.mp4`; host it on YouTube/Vimeo for the
    submission form and link it here.)*

## Submission mechanics (from the current handbook)

- Entry: Interest Form → email invitation → full submission for a named round.
- A full Build submission includes: technical roadmap + milestone plan, budget
  breakdown across tranches, current traction, team skills/experience — the
  four drafts in this folder map 1:1 onto those requirements.
- Open Track submissions get a revision window before a community vote;
  Integration/RFP tracks are panel-decided.
- If awarded: tranches run 10% → 20% → 30% → 40%, each within 90 days of the
  last payment (miss a deadline without notice and the remainder is
  forfeited); KYC/KYB via stellar.org/bd-kyc is required for every individual
  contributor before funds move; SDF may require re-completed KYC at any time.
- Some jurisdictions carry additional restrictions that can limit deployment
  scope — expect the SCF team to flag anything relevant after the Interest
  Form review.
